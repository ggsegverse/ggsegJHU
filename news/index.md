# Changelog

## ggsegJHU 2.0.0

### Breaking changes

- `jhu` and `jhu_3d` data objects have been removed
- Use
  [`jhu_tracts()`](https://ggsegverse.github.io/ggsegJHU/reference/jhu_tracts.md)
  and `jhu_labels()` accessor functions instead
- `ggseg.formats` is now a hard dependency

### Minor changes

- Added
  [`icbm()`](https://ggsegverse.github.io/ggsegJHU/reference/jhu_wm.md)
  atlas (formerly in `ggsegICBM` package)
- Package URLs updated to `ggsegverse` GitHub organisation

## ggsegJHU 1.0.01

- Adapted atlases to ggseg \<= 1.6.0
